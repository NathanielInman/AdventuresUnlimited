# Classes

Nine classes are open to players. Each column header links to that class's max stats; the class reference pages cover the rest:

- [Max stats](max-stats.md): HP, mana, moves and trained stat caps for every race and class
- [Skills](skills.md) and [spells](spells.md): the level each class gets them
- [Specializations](specializations.md): spell group ranks and the spells they unlock
- [Monk](monk.md): mantras, fightstyles, abilities, chi, stances, techniques and combos
