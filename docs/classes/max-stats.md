# Max stats

Every value here is before armor and temple marks. A stat in parentheses is the most you can train it to once your class bonus is added: +2 for the class's primary stat and +1 for its secondary stat. Mages, clerics, thieves and warriors use the same stat for both, so that stat gets +3. Quickling thieves are the one exception: their dexterity stops at 27, not 28.

Hit points, mana and moves stop growing at a cap set by your class and your trained stats:

- HP: class base HP + 75 x con
- Mana: class base mana + 30 x int + 20 x wis
- Moves: 3,750 + 50 x dex
