# Item search

Every item in the area files with a stat bonus, plus every staff, wand, pill, potion and scroll. Narrow it down by name, type, slot, area and level, and the list ranks what's left by a score you control: each stat bonus times its weight. Click an item to see everything the area file says about it.

<ItemSearch />

The score only counts the ten weighted stats. Armor class, saves and weapon dice don't add to it, so compare those in the item's details. The data comes from the area files, not from a running game, so it doesn't know which mob carries an item or what a crafter added later.
